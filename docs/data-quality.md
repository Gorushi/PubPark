# 데이터 품질 원칙 (서울시 구현 기준)

아래는 다음 수집기·앱 연동에 적용할 기준입니다. 현재 전국 수집기에 구현된 검증 규칙은 아닙니다.

- 원본은 보존합니다. 총면수 초과 차량수를 임의로 총면수로 잘라 만차 정답으로 만들지 않습니다.
- 미연계·빈 시각의 0은 주차 차량이 없다는 근거로 사용하지 않습니다.
- 음수·누락·0 이하 총면수·총면수 초과는 상태를 기록하고 잔여면수 학습에서 우선 제외합니다.
- 원본 갱신 시각과 수집 시각을 구분합니다. 지연 기준은 관측한 갱신 주기와 서비스 요구에 따라 설정하고 문서화합니다.
- 총면수 변경 이력을 보존해 당시 총면수를 사용합니다.
- 결측 구간을 실제 관측으로 취급하지 않습니다. 보간 시 긴 공백과 미래값 참조를 피합니다.
- 주차장별 유효 관측 비율·갱신 지연·초과 비율을 측정한 후 예측 대상을 선정합니다.
- 검증은 시간순으로 분할하고 전처리는 훈련 구간에서 학습합니다. 제외 구간과 데이터 커버리지도 함께 보고합니다.
- API 현황의 예측 성능과 실제 입차 성공 확률은 구분합니다.
